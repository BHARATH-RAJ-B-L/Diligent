# Diligent E-commerce Frontend

React (Vite) SPA with React Router, Tailwind CSS, and Context API for cart state.

## Scripts

- `npm run dev` - start Vite dev server
- `npm run build` - production build
- `npm run start` - preview build

## Environment Variables

Create `.env` with:

```
VITE_API_BASE_URL=http://localhost:5000
```

## Pages

- Home (product listing with search & category filter)
- Product detail
- Cart (add/remove/update)
- Checkout (simple form, no payment)
- Login/Register

## Deployment

Deploy to Netlify/Vercel. Set `VITE_API_BASE_URL` to your backend URL.
